# svelte-todo-list

A todo-list made with Svelte.

**Note:** This project uses [pnpm](https://pnpm.io/) as the package manager. Please install pnpm if you don't have it yet (`npm install -g pnpm`).

## Packages Used

- `svelte` – Svelte framework for building UI
- `@sveltejs/kit` – SvelteKit for app structure and SSR
- `@sveltejs/adapter-auto` – SvelteKit adapter for deployment
- `@sveltejs/vite-plugin-svelte` – Vite plugin for Svelte
- `vite` – Fast build tool and dev server
- `sass` – SCSS/Sass support for styling
- `typescript` – TypeScript support

## How to Run Locally

1. **Clone the repository:**

   ```sh
   git clone https://github.com/Kartoffi/svelte-todo-list.git
   cd svelte-todo-list
   ```

2. **Install dependencies:**

   ```sh
   pnpm install
   ```

3. **Start the development server:**

   ```sh
   pnpm dev
   ```
